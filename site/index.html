Modelling, UVs, rigging and animation that behave like Maya.

Same commands, flags, hotkeys, menus and marking menus. MEL and Python scripts run, .ma files open and save, and production rigs pose. Free and open source under the Apache 2.0 licence, for Linux and Windows.

What's in it

Polygon modelling

Maya's polygon commands with construction history. Quad Draw, Multi-Cut, Insert and Offset Edge Loop, Target Weld, Slide Edge, Crease, Create and Append Polygon; symmetry, soft selection, eighteen sculpting brushes.

Soft selection and Quad Draw

B toggles soft selection, with the falloff shown on the vertices. Quad Draw retopologises on a live surface.

NURBS

Curves (CV and EP tools, rebuild, attach, detach, offset, fillets, projection, trims) and surfaces (primitives, loft, revolve, extrude, boundary, birail, nurbsToPoly), with CVs, edit points and isoparms as components.

UVs

Planar, cylindrical, spherical and automatic projections, unfold, layout, cut and sew in the UV Editor, by UV, shell, edge or face.

Materials and textures

lambert, blinn, phong, phongE and surfaceShader with file textures and place2dTexture, assigned to objects or faces. Textured mode (6) in the viewport and the Hypershade.

Rigging

Joints (orient, mirror, insert, segment scale compensate), RP, SC and spline IK, every constraint, smooth skin with weight painting, mirror and copy, dual quaternion; a HumanIK subset (skeleton, definition, control rig, retargeting).

Skinning and deformers

Paint Skin Weights with the influence list in Tool Settings. blendShape in full (Shape Editor, in-betweens, live targets), lattice, wrap, wire, delta mush, softMod, clusters, nonlinears, sculpt, jiggle, shrinkWrap, proximityWrap, curveWarp and more.

Animation

Keys with weighted tangents and infinities, Graph Editor, Dope Sheet, set driven keys, breakdowns, copy and paste keys, baking, motion paths, animation layers, character sets and clips, playblast.

.ma files

Read and written in Maya's layout: deformer chains, constraints, utility nodes, expressions, materials, NURBS, drawing overrides and references with their edits; namespaces, instances, locked nodes, Z up.

Scripting

MEL (procedures, arrays, control flow, backticks, expressions) and Python with aztek.cmds, a maya.cmds shim and maya.api.OpenMaya. Python plug-ins with MPxCommand and MPxNode; scriptJob, scriptNode, evalDeferred.

import maya.cmds as cmds
cube = cmds.polyCube(w=2)[0]
cmds.setKeyframe(cube, at='ty', t=1, v=0)
cmds.setKeyframe(cube, at='ty', t=24, v=5)

Script-built interface

window, layouts, controls, menus and dialogs from MEL or Python become Qt widgets. Attribute-bound controls, AE<type>Template procedures, workspaceControl docking, editors and panels created by script.

The interface you know

Menu sets, shelves, hotkeys, marking menus, the hotbox, channel box, outliner, Attribute Editor, Node Editor, Tool Settings and panel layouts, where your hands expect them.

Windows: run the installer, or unzip and run aztek.exe. Rocky Linux: sudo dnf install ./aztek-*.rpm (Rocky 9 needs EPEL for Qt). Ubuntu: sudo apt install ./aztek_*.deb. All need a Vulkan driver. All builds: Releases.

Build from source

git clone https://github.com/srlegrand/Aztek.git
cd Aztek
./build.sh --deps --run      # Linux
build.bat -Run               # Windows

Needs Rust, CMake, Ninja, Qt 6.4+, Python 3 and, on Windows, Visual Studio 2022 with the C++ workload. Details in the README.
